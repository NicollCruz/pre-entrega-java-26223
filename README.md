# Pre-entrega JAVA
### Objetivo del proyecto
Una empresa necesita desarrollar un sistema que permita administrar los artículos que
comercializa.

Actualmente trabaja con dos tipos de productos: artículos electrónicos y
artículos alimenticios.
Aunque ambos tipos de artículos comparten información, como código, nombre, precio y
categoría, cada uno posee características particulares.

El objetivo de esta preentrega es desarrollar desde cero una aplicación de consola en Java,
aplicando los conceptos de Programación Orientada a Objetos (POO).
El sistema deberá permitir registrar, consultar, modificar, listar y eliminar artículos, utilizando
ArrayList para almacenar la información.

Durante el desarrollo deberán aplicar los siguientes conceptos:
- Clases, objetos, atributos y métodos
- Encapsulamiento, constructores, getters y setters.
- Herencia mediante extends.
- Clases y métodos abstractos.
- Polimorfismo.
- Sobrescritura de métodos mediante @Override.
- Utilización de super y this.
- Implementación del método toString()
- Validaciones y estructuras de control.
- Manejo de listas mediante ArrayList.
